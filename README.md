# mapa-captacao-dados

Robô do **Mapa de Governo · Captação de Recursos**. Baixa todo dia os dados abertos do
Transferegov.br (programas federais, quem pode propor, propostas, convênios e emendas), filtra o que
interessa a prefeituras e publica arquivos pequenos no ramo `dados`, que o servidor do Mapa baixa.

Somente dados públicos do governo federal. Nenhuma senha ou chave neste repositório.
